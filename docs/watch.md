# Live score viewer (`/watch/`)

The page everyone else at the court opens to follow the score on their own phone. No app, no account. It's read-only, except for one button.

## Getting there

- **Scan the QR code** shown in the scorekeeper phone's Settings → Live score, or open the link it shows (`…/watch/#K7Q2XM`).
- **Or type the code:** open `/watch/` and enter the 6-character code. Case, spaces and dashes don't matter.
- The code stays the same week to week, so bookmark the page.

## What's on it

- **Status:**
  - **Live**: a game is being played.
  - **Final**: the last game is over.
  - **Waiting for a game**: no game has started yet.
- **Rules:** e.g. "to 21, win by 2".
- **Result:** after a game, e.g. "door side wins 21–17".
- **Two score panels,** one per basket. The side that's ahead gets a colored border.
- **Recent:** the last 5 baskets, with the time, basket and points ("fix" for a −1 correction).
- **Start next game:** only shown when no game is live. It asks the scorekeeper phone to start a new game at 0–0. The button shows "Waiting for the scorekeeper phone…" until the new game appears. It's turned off while the scorekeeper phone is offline.

## When the score might be out of date

- **"You're offline":** this phone has lost its connection. The score updates when it's back.
- **"Scorekeeper phone is offline":** the phone keeping score has lost its connection, so what you see may be behind. It shows when the last update arrived. The scorekeeper phone keeps scoring anyway, and sends the latest score as soon as it reconnects.
